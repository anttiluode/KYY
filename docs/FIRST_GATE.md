# First gate — 2026-08-10

This note records the first local CPU experiments before any large sweep. They are **smoke results**, not qualification results.

## 1. Naive Laplacian wave candidate failed the easiest gate

Command family: parity, state dimension 16, train length 16.

After 1000 updates:

- `diag_signed`: 100% training-length running accuracy;
- `complex_diag`: 100%;
- `GRU`: reached 100% rapidly in the shorter smoke;
- `geom_wave`: stayed near chance (~0.54 running accuracy).

Interpretation: “second-order wave dynamics” by itself is not enough. The first physically tidy kick-drift parameterization is a poor state-tracking inductive bias for parity under this optimizer/budget.

This result is preserved instead of retuning until it passes.

## 2. Local reciprocal scattering changed the result

`geom_scatter` replaces the Laplacian step with products of token-selective local symmetric orthogonal 2-port cells. Each sweep now has **independent** edge angles. That detail matters: an earlier shared-angle version made the `matching` control accidentally square each isolated reflection to identity (`S^2=I`). Those misleading topology numbers were discarded.

The corrected local ring has enough algebra to learn parity, modulo counting, and non-commutative `S3` composition. The important matched gate is `perm3`.

## 3. Matched `perm3` gate: local ring vs dense Householders

Configuration:

- state dimension: 8
- train length: 16
- train steps: 300
- seeds: 0, 1, 2
- parameters: **110 for both models**
- test lengths: 16, 64, 256

Both `householder2` and `geom_scatter --topology ring` reached 1.000 final-token accuracy at the training length for all 3 seeds.

Interpretation: at matched state and parameter count the local geometric operator is competitive on-length and at 4x length, but the dense Householder product is clearly more robust under extreme length extrapolation in this first gate.

That is **not a geometric win**.

## 4. What the local geometry did establish

The ring scatterer obtains non-commutative global state transformations using only nearest-neighbour 2-port operations. The dense Householder baseline obtains them using global dot products with dense reflector vectors.

Both are O(state) arithmetic in this tiny formulation, but their communication structure is different:

- dense Householder: global reduction / broadcast over all state coordinates;
- ring scatter: strictly local pairwise communication, parallelizable by edge coloring.

That locality may matter for a physical/reconfigurable substrate even when it does not improve the abstract algorithmic benchmark.

The `matching` topology is also informative conceptually. Independent 2D blocks cannot realize the same non-commuting transition family as overlapping local scatterers; fixed 2D rotations are essentially the complex-diagonal control. Overlap creates higher-dimensional non-commuting transformations. This needs a cleaner topology sweep before being treated as a result.

## 5. What remains worth testing

The surviving KYY hypothesis is narrower:

- local geometry may reduce implementation/routing cost even at matched arithmetic count;
- overlapping local couplings may offer an inductive bias when task structure itself is local/spatial;
- locality may improve perturbation, quantization, or hardware robustness;
- a local scatterer may compile naturally to a reciprocal wave fabric where dense Householders do not;
- geometry may become useful when the data themselves are generated by a spatial/wave operator rather than an abstract finite-state group.

A sensible next gate is therefore **not more `perm3` tuning**. It is a task with declared locality plus a topology ablation, while retaining Householder/PD-style baselines.

Especially relevant:

- Grazzi et al., *Unlocking State-Tracking in Linear RNNs Through Negative Eigenvalues* (ICLR 2025 / arXiv:2411.12537).
- Siems et al., *DeltaProduct: Increasing the Expressivity of DeltaNet Through Products of Householders* (arXiv:2502.10297).
- Terzić et al., *Structured Sparse Transition Matrices to Enable State Tracking in State-Space Models* (arXiv:2509.22284).
- Terzić et al., *Flash PD-SSM* (arXiv:2605.19150).
- Lahoti et al., *Mamba-3* (arXiv:2603.15569).

KYY should be read as an experiment about **local geometric support and physical locality**, not as a discovery of structured/orthogonal state transitions.
