# Deep map pass — 2026-08-10

This file records the second literature pass after the first KYY map was drawn.

The purpose is not to collect more citations for their own sake. It is to see whether the apparent valleys survive when search terms are changed and neighbouring literatures are allowed to collide.

## New hard landmark 1 — wave dynamics have already been mapped directly to an RNN

Hughes, Williamson, Minkov & Fan (2019), **Wave Physics as an Analog Recurrent Neural Network**, do something substantially closer to the broad Geometric-Neuron intuition than the first map acknowledged.

They identify a mapping between wave-system dynamics and recurrent neural-network computation, then inverse-design an inhomogeneous physical medium for temporal audio classification while the waveform propagates and scatters through it.

Primary source: https://arxiv.org/abs/1904.12831

### Consequence

The following broad claim is closed:

> "Maybe wave propagation itself can be the recurrent neural computation."

Yes. That is established prior art.

This also means that `coRNN` is not the only ancestor of KYY's wave instinct:

```text
mathematical oscillator RNN                 physical wave RNN
          coRNN                          Hughes et al. 2019
             \                               /
              \                             /
               ------ KYY wave instinct ----
```

Any live KYY residual must be narrower than wave-as-RNN.

## New hard landmark 2 — locality/fan-in versus finite-state capacity is old theory

Horne & Hush, **Bounds on the complexity of recurrent neural network implementations of finite state machines** (NIPS 1993), explicitly study how architectural restrictions affect the number of recurrent nodes needed to implement an `m`-state finite state machine.

Primary source: https://proceedings.neurips.cc/paper/1993/hash/afda332245e2af431fb7b672a68b659d-Abstract.html

Most relevant for KYY: when fan-in is restricted to two, their stated complexity becomes linear in the number of FSM states under the analyzed construction/assumptions, whereas less restricted cases have smaller asymptotic node bounds.

### Consequence

The locality discussion has a much older theoretical ancestor than EUNN.

The right KYY question cannot merely be:

> "Does restricting who talks to whom cost state capacity?"

That question has been studied for decades.

The possible modern residual is much narrower:

> **what is the accuracy / state / parameter / local-depth / global-communication frontier of current structured LRNN transition families on current state-tracking tasks?**

That is an engineering/benchmark frontier, not a new theoretical observation that locality creates a cost.

## New hard landmark 3 — modern state mixing is broader than DeltaProduct and PD-SSM

The current state-tracking field is actively filling in the transition-structure axis.

### Bilinear state transitions

Ebrahimi & Memisevic, **Revisiting Bi-Linear State Transitions in Recurrent Neural Networks** (NeurIPS 2025), treat multiplicative/bilinear hidden-state transitions as a natural hierarchy for state tracking.

Primary source: https://openreview.net/forum?id=xcqrAzYzCj

Their framing is highly relevant to KYY because it treats hidden state as an active participant in computation rather than passive memory.

### Higher-order and block-diagonal LRNNs

Dubinin, Orvieto & Effenberger, **Improved state mixing in higher-order and block diagonal linear recurrent networks** (ICLR 2026 submission), study richer but efficient mixing through higher-order recurrence and dense intra-block transitions. They report permutation-composition results directly in the same family of synthetic problems KYY uses.

Primary source: https://openreview.net/forum?id=fF72TYOKjZ

### Structured Linear CDEs / SLiCEs

Walker et al., **Structured Linear CDEs: Maximally Expressive and Parallel-in-Time Sequence Models** (NeurIPS 2025 spotlight), explicitly unify structured **input-dependent** state-transition matrices, including block-diagonal, sparse, diagonal-plus-low-rank and Walsh-Hadamard forms, while retaining parallel-in-time computation.

Primary source: https://openreview.net/forum?id=HKDyRDzy1E

### Consequence

KYY's baseline set is currently underpowered for any serious state-tracking claim.

The benchmark should eventually know about at least these families conceptually:

```text
diagonal / complex
Householder products
permutation-diagonal sparse
block diagonal
higher order
bilinear
general structured sparse / SLiCE-like
```

That does **not** mean implementing every paper. It means any "geometry wins because it mixes state" interpretation must survive the fact that state mixing itself has many mature efficient parameterizations.

## New hard landmark 4 — low-control token-conditioned dynamics are already a modern design pattern

TCP-SSM (2026), **Token-Conditioned Poles**, starts from shared base real/complex poles and modulates their radius/angle with the current token, with grouping and a lightweight low-rank input path.

Primary source: https://arxiv.org/abs/2605.11563

This is not a geometric mesh, but it cuts directly into KYY Valley A1:

```text
shared slow structure
      +
small token-conditioned modulation
      ->
current recurrent dynamics
```

### Consequence

A1 cannot claim the general pattern:

> "shared base operator + few token controls."

That pattern is occupied.

What remains distinctive, if anything, has to be:

> **the shared structure is explicitly a spatial/delay/physical geometry and the token controls act through that geometry's tied local modes/couplings.**

That is a much smaller target.

---

## New hard landmark 5 — structural wave input encoding is also getting crowded

Wanjura & Marquardt (Nature Physics 2024) already encode data into parameters of a linear scattering system, thereby changing the scattering operator itself.

Hammami et al. (2026) systematically study structural input encoding in a programmable rich-scattering wave system, including mutual coupling and depth.

Primary sources:

- https://www.nature.com/articles/s41567-024-02534-9
- https://arxiv.org/abs/2603.13602

Combined with Hughes et al. 2019, this gives three occupied corners:

```text
wave dynamics -> RNN                   (Hughes 2019)
input -> scattering operator           (Wanjura/Marquardt 2024)
structural wave encoding + depth       (Hammami et al. 2026)
```

The missing conjunction, if it is missing, is specifically **recurrent state tracking through a structurally input-modulated reciprocal scattering operator**.

That is now a high-prior-art-risk bridge, not a broad open field.

# Residuals that survived this pass

## R1 — compress the already learned local operator before inventing a new one

This survives and becomes stronger as a process choice.

Take KYY's existing learned free-edge angle tensor and ask whether it has low-dimensional structure over the geometry.

Candidate bases:

- SVD/PCA over edge axis;
- Fourier modes around the ring;
- graph-Laplacian eigenfunctions;
- low-order polynomial/spline of edge coordinate;
- a tiny CPPN-like coordinate generator.

Then **replace** the free edge angles with reconstructed angles and rerun the frozen model.

Question:

> How many geometry/control degrees of freedom are actually load-bearing?

No architectural novelty is required to answer that.

### Why it matters after TCP-SSM

The interesting quantity is no longer simply low control dimension. It is whether the compressible directions line up with **geometry-derived basis functions** better than with generic low-rank bases.

That gives a real adversarial comparison:

```text
same r

SVD basis               vs               geometry basis
(best generic rank-r)                     (structured rank-r)
```

If geometry cannot approach the generic low-rank reconstruction at matched `r`, geometry has not earned a representational role.

This is currently the cleanest KYY experiment the map suggests.

## R2 — communication-aware benchmark of known transition families

This remains useful but should be presented as a **measurement paper/tool**, not a novel recurrence.

For each transition family, record something like:

```text
state dimension
parameter count
primitive arithmetic
number of global reductions
number of global broadcasts
maximum primitive wire span
local sequential depth
parallel depth
state-tracking accuracy
length extrapolation
```

Horne-Hush tells us locality/capacity trade-offs are old. EUNN/Clements tells us local meshes are old. The modern opportunity, if useful, is to make those old resource questions explicit for today's state-tracking architectures.

This is especially relevant only if KYY is ultimately targeting a local physical fabric rather than a GPU.

---

## R3 — compiler residual

The architecture map keeps getting crowded. The compiler residual looks relatively more coherent each time.

Not:

> "a local mesh can implement a matrix."

Clements/EUNN already own that neighborhood.

Rather:

> **Given a behaviorally trained recurrent transition family, determine the closest realization available to a constrained reciprocal transient-wave substrate, preserve only the observable/load-bearing subspace, and explicitly report unrealizable directions and resource cost.**

That combines:

```text
modern recurrent operator
        +
realization / quotient awareness
        +
constrained reciprocal physical backend
        +
negative-capability report
```

There is still a large inverse-design/photonic-compiler prior-art risk here, so this is not labelled open. But it is much more specific to the TWC/KYY conjunction than another sequence architecture.
