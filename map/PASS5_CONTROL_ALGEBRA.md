# Pass 5 — geometry, control ports, and the Lie algebra behind state tracking

Date: 2026-08-10

> **Correction note.** The first version of `control_algebra_probe.py` used one-pass floating-point Gram-Schmidt and falsely promoted roundoff directions for the `N=12` ring. The probe now normalizes candidates and uses a fresh SVD rank test. The corrected table below was also checked against exact symbolic-rank calculations for the small cases. Keeping this note is intentional: the map is supposed to record how claims get narrower, not erase the embarrassing step.

This pass changes the center of the KYY map again.

The previous candidate valley was a **low-dimensional geometric basis** for token-dependent edge controls. That remains a useful compression diagnostic, but it misses a more powerful mechanism:

> a small *linear* control space can generate a much larger *non-commutative* operator space through repeated composition and commutators.

That is standard geometric-control / dynamical-Lie-algebra mathematics. The useful KYY question is therefore not simply `rank(theta)`.

It is:

> **What dynamical Lie algebra is generated by a fixed local geometry plus a small number of input-controlled local ports, and what state-tracking capability / communication cost follows from that algebra?**

Nothing in this file is claimed as new mathematics.

---

## 1. The commuting trap

Suppose a fixed geometry is represented by one matrix `G`, and every token transition is only a function of that same operator:

```text
A_x = f_x(G)
```

Then all token transitions commute:

```text
A_x A_y = A_y A_x.
```

They live in the same commutative algebra generated by `G`.

So a beautiful homogeneous resonator bank with token-dependent modal gains/phases can still be fundamentally **order-symmetric**. A one-layer transition family with a shared diagonalizing basis cannot faithfully realize general non-Abelian state tracking.

Current sequence-model theory makes this much more precise:

- Shakerinava et al., *The Expressive Limits of Diagonal SSMs for State-Tracking* (ICLR 2026), https://openreview.net/forum?id=5bg5Ru5OML
- Heo et al., *Why Depth Matters in Parallelizable Sequence Models: A Lie Algebraic View* (2026), https://arxiv.org/abs/2603.05573

Heo et al. explicitly classify input-conditioned SSM generators through `Lie({A(x)})` and use commutators / Magnus terms to measure order-sensitive dynamics. Therefore **"Lie algebra explains SSM state tracking" is occupied territory.**

---

## 2. The escape: few controls can generate a huge algebra

Now use

```text
A(x) = G + sum_k alpha_k(x) B_k
```

where `G` is a fixed drift/geometry operator, `B_k` are locally supported controls, and the token supplies only the small coefficient vector `alpha(x)`.

The instantaneous control space has dimension `r`, but repeated evolution produces nested commutators:

```text
[G, B1]
[B1, [G, B1]]
[G, [G, B1]]
...
```

The relevant object is

```text
g = Lie{G, B1, ..., Br}.
```

Its dimension can be far larger than `r`.

This is classical control theory. Importantly, Wang et al. study almost exactly the matrix skeleton used by the toy probe here: bilinear systems on `SO(N)` with a skew-symmetric drift and controlled plane generators `B_ij = E_ij - E_ji`, represented by drift and control interaction graphs. They relate graph structure to the Lie algebra rank condition.

Primary anchors:

- Sontag & Qiao, *Further results on controllability of recurrent neural networks* (1999), https://arxiv.org/abs/math/9902023
- Albertini & D'Alessandro, *The Lie Algebra Structure and Nonlinear Controllability of Spin Systems* (2001), https://arxiv.org/abs/quant-ph/0106115
- Burgarth et al., *Local controllability of quantum networks* (2008), https://arxiv.org/abs/0805.3975
- Godsil & Severini, *Control by quantum dynamics on graphs* (2010), https://arxiv.org/abs/0910.5397
- Wang et al., *Controllability and Accessibility on Graphs for Bilinear Systems over Lie Groups* (2020), https://arxiv.org/abs/2007.11929
- Wang et al., *Structural Controllability on Graphs for Drifted Bilinear Systems over Lie Groups* (2021), https://arxiv.org/abs/2103.12915
- Gago-Encinas et al., *Graph test of controllability in qubit arrays* (2022), https://arxiv.org/abs/2212.04828
- Wiersema et al., *Classification of dynamical Lie algebras of 2-local spin systems on linear, circular and fully connected topologies* (2024), https://doi.org/10.1038/s41534-024-00900-2

So **"few local controls + graph propagation gives global controllability" is not a KYY theorem.** The potential bridge is to modern efficient sequence state tracking and its resource accounting.

## 3. A tiny KYY calculation

For a real `N`-dimensional state define

```text
X_ij = E_ij - E_ji.
```

For a path,

```text
G_path = X_01 + X_12 + ... + X_(N-2,N-1)
B      = X_01.
```

[control_algebra_probe.py](control_algebra_probe.py) numerically closes the algebra under commutators.

For `N = 3 ... 12` it finds

```text
dim Lie{G_path, B} = N(N-1)/2 = dim so(N).
```

So one fixed path drift plus one locally addressed edge generates the full real rotation algebra in every tested size.

There is a simple constructive reason. Starting from `B=X_01`, the neighboring term in the path drift yields `X_02` through a commutator; combining `X_01` and `X_02` yields `X_12`. Repeating the same idea exposes successive adjacent generators, and connected adjacent plane rotations generate `so(N)`.

This is a demonstration of established controllability mathematics, not a novelty theorem.

## 4. The ring exposes a symmetry obstruction

For

```text
G_ring = X_01 + X_12 + ... + X_(N-1,0)
```

with one local control `B1=X_01`, the corrected probe gives:

| N | dim so(N) | path G+B | ring G+B1 | ring G+B1+B2 |
|---:|---:|---:|---:|---:|
| 3 | 3 | 3 | 3 | 3 |
| 4 | 6 | 6 | 4 | 6 |
| 5 | 10 | 10 | 10 | 10 |
| 6 | 15 | 15 | 9 | 15 |
| 7 | 21 | 21 | 21 | 21 |
| 8 | 28 | 28 | 16 | 28 |
| 9 | 36 | 36 | 36 | 36 |
| 10 | 45 | 45 | 25 | 45 |
| 11 | 55 | 55 | 55 | 55 |
| 12 | 66 | 66 | 36 | 66 |

For the even rings tested, the one-control dimensions are

```text
4, 9, 16, 25, 36 = (N/2)^2.
```

That dimension sequence is the dimension of `u(N/2)`, so a **u(N/2)-type symmetry-restricted algebra is a strong hypothesis** for what the probe is seeing. We have not proved the isomorphism here and do not label it a theorem.

Odd rings through `N=11` close to full `so(N)` in the exact/small numerical checks. A second neighboring local control restores full `so(N)` for every even case in the table.

This is exactly the kind of feature the graph-controllability literature warns about: connectivity alone does not always remove drift symmetries when the controlled graph is tiny. Wang et al. explicitly give drifted `SO(N)` examples where a connected union graph is still uncontrollable when the control components are too small.

The KYY lesson is narrower:

> `number of controls` is not enough. **Geometry + symmetry + control placement + Lie closure** determine capacity before training starts.

## 5. Why this changes the low-rank plan

The earlier A1 test asked whether

```text
theta[token, sweep, edge]
```

could be compressed into a small linear geometry basis.

That is still useful, but these quantities are different:

```text
linear control dimension      r
        !=
Lie closure dimension         dim g
        !=
minimum word / pulse depth    needed to reach a target
        !=
communication distance/cost.
```

A two-generator control system can have an `O(N^2)` Lie closure.

There is also a trivial rank trap in the current `perm3` experiment: with only 3 tokens and 2 scatter sweeps, flattening token×sweep against edges produces a matrix with rank at most 6 by shape alone. A low SVD rank there is weak evidence unless a geometry basis competes with an optimal generic basis at much smaller rank or the control family is enlarged.

## 6. The residual after subtraction

Both halves already exist:

```text
modern sequence models:
    Lie algebra / noncommutativity -> state-tracking expressivity

network / bilinear / quantum control:
    graph + sparse local controls -> dynamical Lie algebra / controllability
```

The current search has **not located** a paper whose central design question is exactly:

> **For a linear-time recurrent sequence model, choose a sparse local geometry and a minimal set of input-conditioned local control ports so that their dynamical Lie algebra contains the algebra needed by a target state-tracking problem, while explicitly pricing control count, local communication, and synthesis depth.**

Status: **BRIDGE / UNMAPPED. NOT A NOVELTY CLAIM.**

A useful internal name is **control-algebra efficiency**.

Possible axes:

```text
control ports r
support radius / wire span
primitive applications per token
Lie closure dimension / algebra class
derived length / synthesis depth
commutator mass
state dimension
state-tracking accuracy
length extrapolation
```

The target is not necessarily full `so(N)`. The interesting question is the **smallest locally generated algebra that contains the behaviorally required transitions**.

## 7. No new architecture yet

### Gate L0 — audit models already trained in KYY

Extract token transitions, measure pairwise commutators / commutator mass, and estimate the algebra generated by their transitions in a numerically defensible representation. Compare with `perm3` extrapolation.

### Gate L1 — control-port maps before training

For candidate geometries, compute

```text
(G, B1, ..., Br) -> Lie{G, B1, ..., Br}
```

and search control placement, not neural weights.

### Gate L2 — target-algebra synthesis

Only if L0/L1 remain useful, test the minimum local-control word depth needed to approximate standard state-tracking transitions. This enters optimal-control / gate-synthesis territory, so search that literature before coding.

### Kill condition

If task-relevant algebras require so many local controls or so much sequential local depth that Householder/PD/SLiCE-style transitions dominate under any plausible communication model, close the AI-efficiency branch and retain the result only as physical-control insight.

## 8. Relation to TWC — cautiously

This line resembles TWC because TWC asks which global behavior can be generated by a constrained local physical operator.

But a skew-symmetric `SO(N)` generator is **not** silently equivalent to current TW-1A reciprocal transient semantics. The correct future bridge is:

> derive the actual generator algebra of a chosen TWC/TW-1A state representation, then ask which locally controlled algebra that substrate exposes.

That turns "compile AI into the chip" into a reachability question rather than a metaphor.
