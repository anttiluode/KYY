# Pass 5 — geometry, control ports, and the Lie algebra behind state tracking

Date: 2026-08-10

This pass changes the center of the KYY map again.

The previous candidate valley was phrased as a **low-dimensional geometric basis** for the token-dependent edge controls. That remains a useful compression diagnostic, but by itself it misses a more powerful mechanism:

> a small *linear* control space can generate a much larger *non-commutative* operator space through repeated composition and commutators.

That is standard geometric-control / dynamical-Lie-algebra mathematics. The useful KYY question is therefore not simply `rank(theta)`.

It is:

> **What dynamical Lie algebra is generated by a fixed local geometry plus a small number of input-controlled local ports, and what state-tracking capability / communication cost follows from that algebra?**

Nothing in this file is claimed as new mathematics.

---

## 1. The commuting trap

Suppose a fixed geometry is represented by one matrix `G`, and every token transition is only a function of that same operator:

```text
A_x = f_x(G)
```

for polynomial / analytic functional calculus in a regime where the functions are defined.

Then all token transitions commute:

```text
A_x A_y = A_y A_x
```

because they live in the same commutative algebra generated by `G`.

This is the precise algebraic form of an important KYY warning:

> a beautiful homogeneous resonator bank with token-dependent modal gains/phases can still be fundamentally order-symmetric.

A one-layer transition family with a shared diagonalizing basis therefore cannot faithfully realize general non-Abelian state tracking. Modern theory now states this much more generally for restricted/diagonal SSM families.

Relevant current sequence-model anchors:

- Shakerinava et al., *The Expressive Limits of Diagonal SSMs for State-Tracking* (ICLR 2026), https://openreview.net/forum?id=5bg5Ru5OML
- Heo et al., *Why Depth Matters in Parallelizable Sequence Models: A Lie Algebraic View* (2026), https://arxiv.org/abs/2603.05573

Heo et al. explicitly formulate an input-conditioned SSM generator `A(x)`, classify the model through `Lie({A(x)})`, and use matrix commutators / Magnus terms to quantify order sensitivity. This means **"Lie algebra explains SSM state tracking" is occupied territory.**

## 2. The escape: few controls can generate a huge algebra

Now change the parameterization:

```text
A(x) = G + sum_k alpha_k(x) B_k
```

where:

- `G` is a fixed geometry/drift operator;
- each `B_k` is a locally supported control operator;
- the token/input only supplies the small coefficient vector `alpha(x)`.

The instantaneous control space has dimension roughly `r = number of B_k`.

But the reachable operator algebra is not limited to the linear span of `{G, B_k}`. Repeated evolution generates nested commutators:

```text
[G, B1]
[B1, [G, B1]]
[G, [G, B1]]
...
```

The relevant object is the **dynamical Lie algebra**

```text
g = Lie{G, B1, ..., Br}.
```

Its dimension can be vastly larger than `r`.

This is classical control theory and is especially mature in quantum-control / spin-network work. Graph topology and the placement of a small number of local controls can determine whether the full evolution operator is controllable.

Important anchors:

- Albertini & D'Alessandro, *The Lie Algebra Structure and Nonlinear Controllability of Spin Systems* (2001), https://arxiv.org/abs/quant-ph/0106115
- Burgarth et al., *Local controllability of quantum networks* (2008), https://arxiv.org/abs/0805.3975
- Wang et al., *Controllability and Accessibility on Graphs for Bilinear Systems over Lie Groups* (2020), https://arxiv.org/abs/2007.11929
- Gago-Encinas et al., *Graph test of controllability in qubit arrays* (2022), https://arxiv.org/abs/2212.04828
- Wiersema et al., *Classification of dynamical Lie algebras of 2-local spin systems on linear, circular and fully connected topologies* (2024), https://doi.org/10.1038/s41534-024-00900-2

So **"few local controls + graph propagation gives global controllability" is also not a new KYY theorem.**

The bridge to modern sequence state tracking is the interesting part.

## 3. A tiny KYY calculation

For a real `N`-dimensional state define the local skew generator

```text
X_ij = E_ij - E_ji
```

which infinitesimally rotates coordinates `i` and `j`.

For the path geometry define one fixed drift

```text
G_path = X_01 + X_12 + ... + X_(N-2,N-1)
```

and expose only one local control port

```text
B = X_01.
```

The script [control_algebra_probe.py](control_algebra_probe.py) numerically closes the Lie algebra under commutators.

For `N = 3 ... 12` it finds

```text
dim Lie{G_path, B} = N(N-1)/2 = dim so(N).
```

In other words, **two declared primitive generators — one fixed path-wide drift and one local control edge — generate the full real rotation algebra in every tested size.**

This numerical observation has an elementary constructive explanation. Start with `B = X_01`.

Because only the neighboring term in `G_path` fails to commute with it,

```text
[B, G_path] = X_02.
```

Then

```text
-[X_01, X_02] = X_12.
```

Once successive adjacent generators are available, commutators generate longer-range `X_ij`, and these in turn isolate the next adjacent edge inductively. The adjacent `X_(i,i+1)` generators generate all of `so(N)`.

This is not presented as a novelty theorem; it is the simplest concrete demonstration of the design principle that matters for KYY.

## 4. Geometry really does change the algebra

The same probe gives a useful topology control.

For the **ring** drift

```text
G_ring = X_01 + X_12 + ... + X_(N-1,0)
```

with one local control `B = X_01`, the tested closure is:

| N | dim so(N) | path G+B | ring G+B | ring G+B1+B2 |
|---:|---:|---:|---:|---:|
| 3 | 3 | 3 | 3 | 3 |
| 4 | 6 | 6 | 4 | 6 |
| 5 | 10 | 10 | 10 | 10 |
| 6 | 15 | 15 | 9 | 15 |
| 7 | 21 | 21 | 21 | 21 |
| 8 | 28 | 28 | 16 | 28 |
| 9 | 36 | 36 | 36 | 36 |
| 10 | 45 | 45 | 25 | 45 |
| 11 | 55 | 55 | 55 | 55 |
| 12 | 66 | 66 | 36 | 66 |

For the even rings in this small sweep, one local control leaves a restricted algebra; adding a second neighboring local control restores full `so(N)`. Odd rings happened to close fully with one control in the tested sizes.

This parity/topology pattern should be regarded as a **numerical map feature**, not a new theorem, until connected carefully to the established graph-controllability literature.

But it demonstrates the KYY point cleanly:

> `number of controls` is not enough to describe capacity. **Geometry + control placement + Lie closure** matter together.

## 5. Why this changes the earlier low-rank plan

The old A1 test asked whether

```text
theta[token, sweep, edge]
```

could be compressed into a small linear geometry basis.

That is still worth measuring, but a low linear rank is not the whole story.

A two-dimensional control span can have a Lie closure of dimension `O(N^2)`.

So these are different quantities:

```text
linear control dimension      r
        !=
Lie closure dimension         dim g
        !=
minimum word / pulse depth    needed to reach a target
        !=
communication distance/cost
```

KYY should measure all four rather than equating "small controller" with "small computational family."

There is also a trivial rank trap in the current `perm3` experiment: with only 3 tokens and 2 scatter sweeps, flattening token×sweep against edges produces a matrix with rank at most 6 **by dimension alone**. A low SVD rank on that tensor would therefore be weak evidence unless geometry beats random/generic bases at much smaller rank or the vocabulary/control family is scaled up.

## 6. The new residual after prior-art subtraction

Both halves are known separately:

```text
modern sequence models:
    Lie algebra / noncommutativity -> state-tracking expressivity

network / quantum control:
    graph + few local controls -> dynamical Lie algebra / controllability
```

The current map has not yet located a work whose central design question is exactly:

> **For a linear-time recurrent sequence model, choose a sparse physical/graph geometry and a minimal set of locally supported input-conditioned control ports so that their dynamical Lie algebra matches the algebra required by a target class of state-tracking computations, while explicitly pricing local communication and control depth.**

Status: **BRIDGE / UNMAPPED. NOT A NOVELTY CLAIM.**

This is substantially sharper than "geometry-generated operator."

A useful name inside KYY is:

## control-algebra efficiency

Possible metrics:

```text
control ports r
support radius / wire span
primitive applications per token
Lie closure dimension dim(g)
derived length / algebra class
commutator mass
state dimension
state-tracking accuracy
length extrapolation
```

The interesting quantity is not maximum algebra dimension alone. Full `so(N)` may be unnecessary and expensive to synthesize. The goal is the **smallest locally generated algebra that contains the task-relevant transitions**.

## 7. No new architecture yet

The next work should still be diagnostic.

### Gate L0 — audit the models we already have

For each trained KYY model:

1. extract token transition matrices;
2. compute pairwise commutator norms;
3. estimate the dimension/class of the Lie algebra generated by their infinitesimal/log generators where that operation is numerically meaningful;
4. compare those diagnostics with `perm3` length generalization.

This asks whether the successful models actually occupy a sufficiently noncommutative operator family.

### Gate L1 — control-port map before training

For candidate physical/local geometries, compute

```text
(G, B1, ..., Br) -> dim Lie{G, B1, ..., Br}
```

before any optimizer is involved.

Search over **control placement**, not neural weights.

### Gate L2 — target-algebra synthesis

Only if L0/L1 remain interesting, ask whether short products of locally generated flows can approximate the actual transition generators required by `S3`, `A5`, `S5`, or other field-standard state-tracking targets.

This is where pulse/word depth becomes a resource axis.

### Kill condition

If useful state-tracking algebras require so many local controls or so much sequential local depth that Householder/PD/SLiCE-style transitions dominate under any plausible communication model, keep this as a physical-control curiosity and close the AI-efficiency branch.

## 8. Relation to TWC — cautiously

This line smells like TWC because TWC also asks what global response/operation can be generated by a constrained local physical operator.

But KYY must not silently identify a skew-symmetric orthogonal generator with the current reciprocal TW-1A semantics. The state representations and physical constraints differ.

The possible future bridge is narrower:

> derive the actual generator algebra of the chosen TWC/TW-1A transient state representation, then ask which locally controllable algebra that substrate exposes.

That would turn "compile AI into the chip" into a concrete reachability question rather than a metaphor.

The best KYY question after pass 5 is no longer

It is now

> **Can geometry make a *small control interface* generate the right noncommutative operator algebra cheaply?**

That question is built from known mathematics on both sides. The exact bridge still needs a deeper search before architecture code.
