# Pass 3 — searching the exact residual

Date: 2026-08-10

The second pass left a candidate:

> fixed geometry + few token-dependent controls -> larger local recurrent operator -> state tracking.

This pass searched the pieces of that sentence more adversarially.

---

## Hit: adaptive/input-dependent unitary recurrence is already occupied

**Karuvally et al. — Bridging Expressivity and Scalability with Adaptive Unitary SSMs (AUSSM)** (2025)  
https://arxiv.org/abs/2507.05238

AUSSM uses **input-dependent skew-symmetric recurrence** to obtain unitary evolution and studies formal-language/state-tracking expressivity. It includes parity and modular-arithmetic style evaluations and develops efficient training machinery.

This matters because a tempting KYY reframe after EUNN was:

> "Fine, EUNN is fixed. KYY's local unitary mesh is token-conditioned."

That distinction is not enough.

The broad cell

```text
input-dependent + unitary + recurrent + state tracking
```

is occupied.

What AUSSM does **not** supply, in the current reading, is KYY's proposed fixed spatial geometry / local physical tying. That difference is now the only reason to keep this branch separate.

---

## Hit: dynamic generation of filters/operators is old

**De Brabandere et al. — Dynamic Filter Networks** (2016)  
https://arxiv.org/abs/1605.09673

Dynamic Filter Networks generate filters conditioned on the input and explicitly note recurrent combinations/applications.

Together with **HyperNetworks** and **ISAN**, this occupies the generic pattern:

```text
input/context
     |
     v
small generator/controller
     |
     v
current weights / current operator
```

So Valley A1 cannot be justified by saying:

> "instead of learning every operator directly, generate it from a small network."

That is old.

## Hit: shared base dynamics + token modulation is current SSM design

**TCP-SSM — Token-Conditioned Poles** (2026)  
https://arxiv.org/abs/2605.11563

TCP-SSM uses shared base real/complex poles and bounded token-conditioned radius/angle modulation, plus grouped pole sharing and a low-rank input path.

This occupies another tempting KYY sentence:

```text
slow shared operator anatomy
        +
fast small token controls
        ->
current dynamics
```

Again, geometry is the only possible residual.

### What was located

- HyperNEAT / CPPN indirect encoding: coordinates/geometry generate large connectivity patterns.
- HyperNetworks: compact conditioned networks generate another model's weights.
- Dynamic Filter Networks: input-conditioned generation of filters/operators.
- ISAN: token/input selects recurrent affine operator.
- EUNN: local Givens/unitary recurrent mesh.
- AUSSM: adaptive input-dependent unitary SSM with state-tracking motivation.
- TCP-SSM: shared base poles with token-conditioned dynamics.
- GraphCON: graph geometry determines coupled oscillator structure.
- modern sparse/block/bilinear LRNNs: rich state mixing under state-tracking benchmarks.

### What this pass did *not* locate

An exact primary-source match to all of:

```text
1. fixed explicit spatial/delay geometry G
2. local recurrent support inherited from G
3. token-by-token control dimension r deliberately << edge/operator dimension
4. Q_t generated by a tied function F(G, a_t)
5. modern finite-state/state-tracking benchmark
6. comparison against modern expressive LRNN transitions
```

Status: **UNMAPPED AFTER THIS PASS**, not novel.

There are enough strong neighbours that a different keyword, citation chain, or older structured-RNN literature may still close it.

# The residual is now mathematical, not verbal

To stop the residual moving every time a paper is found, define it as a restriction.

Let a local mesh have `E` edge controls per token in the unconstrained model:

```text
theta_t in R^E
```

KYY-A1 would require

```text
theta_t = Phi(G) a_t
```

or a comparably explicit nonlinear tied generator, with

```text
a_t in R^r,   r << E.
```

`Phi(G)` must be determined by declared geometry/physics rather than being an arbitrary learned dense `E x r` matrix, otherwise this reduces to ordinary low-rank/hypernetwork parameterization.

Examples that would actually count as geometric restrictions:

```text
Phi_k(e) = Fourier mode of edge position
Phi_k(e) = graph-Laplacian eigenfunction
Phi_k(e) = function of edge length / orientation / node coordinates
Phi_k(e) = physical modal sensitivity of a declared substrate
```

This gives us an invariant residual:

> **Does a geometry-derived basis span the behaviorally useful token-conditioned transition family with unusually small `r`?**

That question survives EUNN, AUSSM, HyperNetworks, Dynamic Filters and TCP-SSM because those landmarks do not by themselves say that a declared spatial geometry is an efficient basis for the required operator family.

---

# The adversary that makes this worth testing

A geometry basis must not be compared only to the free-edge model.

At each rank/control dimension `r`, compare:

```text
GEOMETRY BASIS
Phi_G a_t

vs

GENERIC BEST LOW-RANK BASIS
Phi_SVD a_t

vs

RANDOM OR LEARNED DENSE BASIS
Phi_dense a_t
```

All three get the same `r`.

Then measure both:

```text
operator reconstruction error
state-tracking behavior after replacement
```

This is important because a low-rank result alone would merely rediscover compression. The Geometric Neuron earns something only if **geometry is a good basis**, not merely if the operator is compressible.
