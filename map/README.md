The Geometric Neuron intuition lives in a conjunction rather than one mechanism:


## The important change from pass 5

The previous map focused on whether the learned edge-angle tensor had a small linear geometry basis. That is still a useful compression test, but it is **not the main capacity measure**.

A tiny instantaneous control span can generate a huge noncommutative family through repeated commutators.

The small probe in this folder illustrates the point. Let

```text
X_ij = E_ij - E_ji
G_path = X_01 + X_12 + ... + X_(N-2,N-1)
B = X_01
```

Then the numerical Lie closure satisfies, for every tested `N=3..12`,

```text
dim Lie{G_path, B} = dim so(N) = N(N-1)/2.
```

So **one fixed local path geometry plus one locally addressable control edge can generate the full rotation algebra**, despite exposing only two primitive generators. This is standard controllability mathematics, not a KYY novelty claim; what matters is what it suggests for the sequence-model question.

On an even ring, the same one-control construction stays in a smaller algebra in the tested sizes; adding a second neighboring control restores full closure. Geometry and control placement therefore change the generated algebra before training enters the story.

See [PASS5_CONTROL_ALGEBRA.md](PASS5_CONTROL_ALGEBRA.md).

## Current pin on the map

Both sides of the bridge already exist:

```text
modern sequence models:
    noncommutative / Lie algebra structure -> state-tracking expressivity

network and quantum control:
    graph + few local controls -> dynamical Lie algebra / controllability
```

The exact KYY question currently left after subtraction is:

> **Can a sparse local geometry plus a very small set of input-conditioned control ports generate the task-relevant noncommutative operator algebra with a better control/communication/depth trade-off than existing efficient recurrent transitions?**

Status: **BRIDGE / UNMAPPED. NOT A NOVELTY CLAIM.**

The proposed metric is **control-algebra efficiency** rather than merely parameter count:

```text
number of control ports
support radius / wire span
primitive applications per token
Lie closure dimension / algebra class
commutator mass
state dimension
state-tracking accuracy
length extrapolation
```

The goal is not maximum algebra dimension. Full `so(N)` may be unnecessary. The goal is the **smallest locally generated algebra that contains the behaviorally required transitions**.

## No new architecture yet

The next gates are diagnostics:

1. audit the transition algebra of models already trained in KYY;
2. map Lie-closure dimension versus control placement on candidate geometries;
3. only then ask whether short local-control words can synthesize the transition algebra required by field-standard state-tracking tasks;
4. kill the AI-efficiency branch if the required local depth/control count makes existing Householder/PD/SLiCE-style transitions clearly superior.
