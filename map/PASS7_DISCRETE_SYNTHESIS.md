# Pass 7 — finite-group state tracking is a synthesis problem, not a Lie-dimension contest

Date: 2026-08-10

Pass 5 found a useful bridge from local geometry to dynamical Lie algebras. Pass 7 catches the overreach before it becomes a new architecture:

> **A large reachable Lie algebra is not the target on a finite-group state-tracking task.**

For `perm3`, the desired computation is discrete. The token transitions should realize the relations of the finite group `S3` (or at least the same behavioral quotient). The Lie algebra of a finite group is trivial.

So the relevant resource question is not

```text
how large is Lie{G,B1,...,Br} ?
```

by itself.

It is closer to

```text
how cheaply can the available local primitives synthesize
an exact / stable representation of the task transition group or monoid?
```

This moves KYY from **controllability** to **behavior-aware operator synthesis**.

---

## 1. Why this may explain the first KYY result

The first matched `perm3` gate showed:

- dense two-Householder transitions: stable extreme extrapolation in the tested seeds;
- local free-edge scatter mesh: perfect on training length, but some seeds accumulated severe error by length 256.

One plausible mechanism is now obvious.

For a finite group, if the learned token matrices satisfy the defining relations only approximately,

```text
S^2 ~= I
R^3 ~= I
S R S ~= R^-1,
```

then a tiny per-token operator error can compound over a long word.

A parameterization that lands on an exact finite-order representation has no such algebraic drift.

This is a hypothesis for KYY, not an explanation already established by the current benchmark. `operator_algebra_audit.py` was added specifically to measure relation defects and long-horizon behavior without assuming they must correlate.

---

## 2. This exact-matrix viewpoint is already in the state-tracking literature

Grazzi et al. (ICLR 2025) construct finite-state tracking with permutation matrices and products of generalized Householder reflections. Their proof explicitly uses:

- Cayley's theorem to represent transition groups by permutations;
- a distinct starting vector so different permutations produce distinct hidden states;
- decomposition of permutation matrices into swaps / Householder reflections;
- exact rotations for modular counting.

Primary source:

- Grazzi et al., *Unlocking State-Tracking in Linear RNNs Through Negative Eigenvalues* (ICLR 2025), https://openreview.net/forum?id=UvTo3tVBk2

Their construction is extremely close to the `perm3` oracle below. Therefore **"track permutations by multiplying a distinct vector by permutation matrices" is occupied prior art.**

A 2026 follow-up on deterministic versus probabilistic permutation tracking states explicitly that the deterministic case admits a compact `n-1`-dimensional representation, while uncertainty generally requires a much larger belief representation:

- Siems et al., *Learning State-Tracking from Code Using Linear RNNs* (2026), https://arxiv.org/abs/2602.14814

So compact faithful group representations are tools/baselines, not a KYY novelty.

## 3. Exact local oracle for KYY's own `perm3`

KYY's task uses

```text
e = identity
s = (0 1)
r = cycle (0 -> 1 -> 2 -> 0).
```

Take

```text
h0 = (1,2,3)^T.
```

Let `P_g` be the 3x3 permutation matrix for group element `g`, with

```text
P_g e_i = e_(g(i)).
```

Use recurrence

```text
h_t = P_(x_t) h_(t-1).
```

Then after word `w`,

```text
h_t = P_w h0.
```

Because the entries of `h0` are distinct, its orbit contains all six permutations. They all have equal norm. Therefore a fixed linear nearest-template readout

```text
logit_g(h) = (P_g h0)^T h
```

decodes the group state exactly: the matching prototype has strictly maximal dot product.

### Local factorization

On the path

```text
0 -- 1 -- 2
```

the primitive adjacent swap matrices are exactly 2-port reflections.

The three token transitions have local depths

```text
identity: 0
s=(01):   1
r:        2 adjacent swaps.
```

Thus the exact resource point for this benchmark is:

```text
state channels:              3
trainable recurrence params: 0
max wire span:               1
max local primitive depth:   2
group relation error:        0
length drift:                0
```

[exact_perm3_local_oracle.py](exact_perm3_local_oracle.py) implements this construction and checks the exact relations against KYY's task convention. The test suite runs it for 2048 random tokens and requires bit-exact class tracking.

Again: this is a **known-construction oracle baseline**, not a new KYY architecture.

## 4. General symmetric groups make the point even sharper

The symmetric group `S_n` is generated by adjacent transpositions

```text
s_i = (i, i+1)
```

with the Coxeter relations

```text
s_i^2 = e
s_i s_j = s_j s_i       for |i-j| > 1
s_i s_(i+1) s_i = s_(i+1) s_i s_(i+1).
```

In the natural permutation representation, every `s_i` is literally a nearest-neighbour 2-port swap/reflection on an `n`-site line.

A generic vector with distinct entries has an orbit of size `n!`, so an `n`-dimensional real recurrent state can distinguish all group elements under this representation. Representation theory can reduce dimensions further in some formulations (the standard faithful representation has dimension `n-1` for the usual range of `n`).

This means that a standard permutation-composition benchmark is **already geometrically local under a natural representation**.

That is not a KYY win. It is a warning about benchmark interpretation:

> if we give each input symbol an adjacent transposition, locality is handed to the model by the problem presentation.

For fair resource comparisons, KYY must report the generator presentation. Random/global permutations and adjacent generators are very different compilation problems even when they generate the same group.

## 5. Lie closure still matters — but as a feasibility test

The Pass-5 dynamical Lie algebra remains useful when the physical/local primitive set is continuous and a target discrete operator must be synthesized from it.

The hierarchy is now:

```text
local physical/control generators
        |
        |  Lie closure: is target synthesis even reachable?
        v
reachable continuous group
        |
        |  word / pulse synthesis
        v
exact or approximate token operators
        |
        |  observable quotient
        v
target finite transition group/monoid
```

So Lie closure answers **can**, not **how cheaply** and not **what behavior is required**.

The relevant post-controllability quantities are:

```text
minimum local word depth
minimum number of active control ports
approximation error to defining relations
error accumulation under long products
wire span / synchronization cost
observable task error.
```

This is closely related to mature gate/circuit synthesis and optimal-control literature. KYY should treat those as prior art rather than invent a "compiler" vocabulary from scratch.

Representative boundaries:

- exact / approximate unitary gate synthesis;
- hardware-connectivity-aware circuit synthesis;
- uniform finite generation / switch-count control theory;
- optimal control on Lie groups.

---

## 6. The new benchmark rule

For every algebraic state-tracking task, add an **oracle resource floor** before comparing trainable architectures.

The report should include:

```text
target transition monoid/group
chosen generator presentation
smallest known faithful / sufficient representation used as baseline
exact local primitive depth for each token when known
state dimension
relation defect
long-horizon drift.
```

Then ask what a learned architecture buys beyond that oracle:

- learning the representation from raw input rather than being handed symbolic generators;
- sharing one operator family across many tasks;
- handling non-invertible transitions;
- handling partial observability / probabilistic belief state;
- integrating content and state rather than solving a synthetic group word problem.

Those are much closer to real language-model difficulties.

---

## 7. What remains potentially interesting for KYY

The strongest residual is no longer:

> local geometry can represent a noncommutative state machine.

That is trivially true for permutation groups and well known.

A sharper residual is:

> **Given a task transition monoid/group and a constrained physical/local primitive set, automatically find a low-dimensional behaviorally sufficient representation and compile its token transitions into minimum-cost local words, with an explicit exactness/long-horizon guarantee.**

This combines known areas:

- automata / transition monoids;
- representation and realization theory;
- graph/local controllability;
- gate/operator synthesis;
- recurrent state tracking.

Status: **BRIDGE / HIGH PRIOR-ART RISK. NOT A NOVELTY CLAIM.**

The useful next step is not another learned architecture. It is to turn the KYY benchmark into a **compiler audit** where learned models are compared against the best exact algebraic implementation we can construct for the task.
