# Pass 13 — transport and pinch: one irreversible primitive is algebraically enough

Date: 2026-08-10

This pass turns the bicycle-chain picture into exact finite transformation algebra.

The picture is:

```text
local reversible motion
        +
one elementary irreversible pinch / merge
        ->
rich finite-state behavior
```

Again, the theorem underneath it is old.

The useful KYY contribution at this stage is only an **exact resource oracle** under declared local primitive libraries.

---

# 1. Classical theorem: S_n plus one defect-1 map generates T_n

Let

```text
T_n = all functions {0,...,n-1} -> {0,...,n-1}
S_n = all bijections on the same set.
```

`T_n` has `n^n` elements.

A transformation has defect 1 if its image has size `n-1`.

A classical result says that the full finite transformation semigroup is generated by generators of `S_n` together with any chosen defect-1 transformation. Equivalently, `T_n` has rank 3 for `n >= 3`: two permutations can generate `S_n`, and one singular map supplies irreversibility.

A convenient reference statement appears in Gomes & Howie, *On the ranks of certain finite semigroups of transformations*:

https://doi.org/10.1017/S0305004108001827

and standard computational-algebra references expose the same generating fact.

So the abstract statement

> arbitrary deterministic finite-state evolution = reversible permutations + one elementary singular operation

is not new.

# 2. The local version is also established mathematics

Cameron, Castillo-Ramirez, Gadouleau & Mitchell, *Lengths of words in transformation semigroups generated by digraphs* (J. Algebraic Combinatorics 2017):

https://doi.org/10.1007/s10801-016-0703-9

associate to each directed graph edge `(a,b)` the rank-`n-1` idempotent

```text
a -> b
```

that maps state `a` to `b` and fixes every other state.

They study the semigroup generated by such edge-local merges and the minimum word lengths needed to express transformations.

Therefore even

```text
"price irreversible transformations by graph-local word length"
```

has direct prior art.

KYY should use that theory, not rename it.

# 3. KYY's physical reading: transport versus pinch

For a path realization, choose two primitive types.

## Reversible transport

Adjacent swap:

```text
S_i: i <-> i+1
```

This preserves every state distinction.

## Irreversible pinch

Directed merge:

```text
E_i: i -> i+1
```

with all other states fixed.

This lowers transformation rank by one.

The path swaps generate `S_n`.

Therefore path swaps plus even a **single fixed pinch** such as `0 -> 1` generate all of `T_n`: use the swaps to conjugate/reroute the singular operation to the needed state labels.

That is the exact algebraic form of:

```text
move distinctions around
        |
        v
bring the right pair to the write site
        |
        v
merge them
        |
        v
move again
```

The theorem is old. The hardware cost depends on how expensive the routing is.

# 4. Exact small-n resource oracle

`local_transformation_monoid_oracle.py` enumerates `T_n` exactly for small `n` and BFS-compiles every transformation under several primitive libraries.

Libraries:

```text
GLOBAL-3
    n-cycle + one transposition + one defect-1 pinch
    minimal-ish abstract generator count, but the n-cycle is global

PATH + ONE PINCH
    every adjacent swap
    + only fixed merge 0 -> 1

PATH + ALL PINCHES
    every adjacent swap
    + both merge directions on every adjacent edge

PARALLEL PATH + ONE PINCH
    disjoint adjacent swaps may run simultaneously
    + only fixed merge 0 -> 1

PARALLEL PATH + ALL PINCHES
    any disjoint adjacent swaps / directed merges may share one layer
```

The script verifies that each library generates all `n^n` transformations for the tested sizes.

Exact BFS results currently measured for `n <= 6`:

| n | |T_n| | global-3 max | path + 1 pinch | path + all pinches | parallel + 1 pinch | parallel + all pinches |
|---:|---:|---:|---:|---:|---:|---:|
| 2 | 4 | 2 | 2 | 1 | 2 | 1 |
| 3 | 27 | 5 | 6 | 3 | 6 | 3 |
| 4 | 256 | 9 | 11 | 6 | 9 | 4 |
| 5 | 3125 | 16 | 19 | 10 | 13 | 5 |
| 6 | 46656 | 23 | 28 | 15 | 17 | 6 |

These numbers are **computed resource points, not claimed formulas**.

Two patterns are conspicuous in this tiny sweep:

- sequential `path + all pinches` has worst depth `1,3,6,10,15`, the triangular numbers;
- fully parallel local layers have worst depth `1,3,4,5,6`.

Do not promote those patterns to theorems without proving/searching them. Word-length questions for graph-generated transformation semigroups are already a research field.

# 5. This gives a concrete reset-port trade-off

The oracle exposes a resource axis KYY had only described verbally:

```text
few irreversible control sites
    -> cheap physical write hardware
    -> more reversible routing depth

many local irreversible sites
    -> more write/reset hardware
    -> less routing depth
```

For example at `n=6` in this exact toy:

```text
one fixed pinch, parallel swaps:
    worst exact depth = 17

pinch available on every local edge, parallel local layers:
    worst exact depth = 6
```

Again, the particular numbers are toy/compiler numbers. The structural trade-off is what matters.

That is a much better interpretation of "locality costs depth" than counting FLOPs alone.

# 6. Relation to Sigma-chains

Pass 11 gives a decomposition across **components**:

```text
permutation/reset automaton
    -> next local component
    -> next local component
```

Pass 13 gives a decomposition **inside one component's transition map**:

```text
local swaps
    +
local rank-lowering merges
    ->
finite transformation word
```

They are complementary levels.

A fully explicit KYY compiler could therefore have two locality layers:

```text
behavioral automaton
        |
        v
Sigma-chain / Krohn-Rhodes-like component decomposition
        |
        v
each component transition
        |
        v
local transport-and-pinch word on physical substrate
```

Almost every ingredient is established theory. The question is whether putting them under one hardware cost model gives a useful sequence-machine design.

---

# 7. Relation to the wave/plastic picture

Do not identify finite permutations literally with physical waves.

But the information-flow analogy is disciplined:

```text
approximately reversible / conservative propagation
    -> preserves distinctions while moving/mixing them

plastic / dissipative / reset event
    -> can deliberately merge distinctions
```

A local physical wave medium could potentially implement the transport cheaply in parallel, while sparse plastic/reset sites implement the pinch.

Whether that is actually cheaper depends on propagation time, precision, control, dissipation, and readout cost. The algebra alone cannot answer it.
