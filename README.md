# KYY

**KYY** (*kyy* = viper in Finnish) is a small, falsifiable test of one idea from the Geometric Neuron / Transient Wave Compiler line:

> Does a recurrent transition whose structure is **generated by a sparse geometry** provide a useful inductive bias for state tracking, compared with equally small diagonal/selective recurrent operators?

This repository is deliberately **not** a claim that geometric neurons replace Mamba or Transformers. It is an entry ticket: put a geometry-derived operator on the same start line as standard efficient recurrences and measure what happens.

## Candidate: Geometric Wave State (GWS)

The candidate state is a sparse second-order wave body with position `q` and momentum `p` on a graph. For each input token, the graph's edge couplings and damping are modulated, then one kick-drift step is applied:

```text
p[t+1] = rho(x_t) p[t] - dt * (k0 q[t] + L_w(x_t) q[t]) + drive(x_t)
q[t+1] = q[t] + dt * p[t+1]
```

`L_w` is a weighted graph Laplacian. On the default ring, each node touches only two neighbours, so the recurrent body is O(state) per token. Global behaviour arises through repeated local propagation and the graph's modes.

The important commitment is **not resonance by itself**. Modern SSMs already use complex/oscillatory state. The commitment being tested here is:

> transition structure comes from a geometry (incidence / Laplacian / delays), rather than from independent diagonal state channels.

## Baselines

The harness includes:

- `diag_signed` — token-selective signed diagonal recurrence.
- `complex_diag` — token-selective 2D rotary/complex blocks.
- `gru` — dense nonlinear recurrent reference.
- `geom_wave` — KYY's sparse geometry-derived second-order recurrence.

All runs report trainable parameter count and state size. The point is not to handicap the baselines; it is to discover whether geometry earns its cost.

## Tasks

The first gate uses synthetic state-tracking tasks because they are cheap, exact, and length-generalization can be tested aggressively:

- running parity;
- running count modulo 3;
- set/reset/toggle flip-flop;
- composition of generators of `S3` (non-commutative finite-state tracking).

Train at one length, then evaluate at longer lengths without retraining.

## Run

```bash
pip install -r requirements.txt
python benchmark.py --quick
```

A fuller sweep:

```bash
python benchmark.py --models diag_signed complex_diag geom_wave gru \
  --tasks parity mod3 flipflop perm3 \
  --train-length 32 --test-lengths 32 64 128 256 \
  --steps 1500 --seeds 0 1 2
```

Results are written as JSON/CSV under `results/`.

## What would count as interesting?

Not one lucky seed. A useful signal would be one of:

1. `geom_wave` solves a state-tracking task that a matched diagonal recurrence systematically fails;
2. it reaches the same accuracy with materially smaller state;
3. it generalizes to longer sequences more reliably at matched state and parameter budget;
4. graph topology produces a reproducible capability difference (ring vs path vs disconnected controls);
5. the learned wave modes reveal a structural reason for the capability difference.

A null result is also valuable: if complex diagonal recurrence matches or beats the geometric operator everywhere, the stronger Geometric-Neuron architectural claim is not earned by these tasks.

## Research hygiene

KYY begins after checking obvious neighbouring lines: selective SSMs, complex-valued Mamba-style recurrences, negative-eigenvalue state tracking, graph SSMs, block-diagonal LRNNs, and spectral sequence models. The broad idea “structured recurrence instead of quadratic attention” is established. KYY tests the narrower geometry-derived transition hypothesis.

The project rule is the same one that emerged from TWC:

> **Do not infer more internal structure than the experiment identifies.**
