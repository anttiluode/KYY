# KYY

**KYY** (*kyy* = viper in Finnish) is a small, falsifiable test of one idea from the Geometric Neuron / Transient Wave Compiler line:

> Does a recurrent transition whose structure is **generated by a sparse geometry** provide a useful inductive bias for state tracking, compared with equally small generic structured recurrences?

This is deliberately **not** a claim that geometric neurons replace Mamba or Transformers. The broad architecture idea — persistent state updated by a compact structured operator — is already the SSM/LRNN field. KYY asks a narrower question: whether *local geometric support* is ever useful once we compare against the algebra that modern state-tracking work already knows is powerful.

## Two geometric candidates

### `geom_wave`: Laplacian kick-drift body

A sparse second-order wave body with position `q` and momentum `p` on a graph:

```text
p[t+1] = rho(x_t) p[t] - dt * (k0 q[t] + L_w(x_t) q[t]) + drive(x_t)
q[t+1] = q[t] + dt * p[t+1]
```

`L_w` is a weighted graph Laplacian. This was the first implementation because it is closest to the TWC/physical-wave picture.

**First smoke result:** it did *not* learn running parity in the same budget where signed-diagonal, complex-diagonal, GRU, and the later scattering candidate did. The failure is preserved as evidence rather than tuned away.

### `geom_scatter`: local reciprocal scattering network

The second candidate is closer to a lossless wave/scattering fabric. Each physical edge applies a symmetric orthogonal 2-port cell

```text
[a']   [ cos(theta)   sin(theta)] [a]
[b'] = [ sin(theta)  -cos(theta)] [b]
```

and disjoint edges are updated in checkerboard phases. The angle is token-selective. A ring therefore composes **local reciprocal reflections** into a global orthogonal transition while requiring only O(E)=O(state) work.

This version immediately learned parity, modulo-3 counting, and non-commutative `S3` permutation composition in local smoke tests. That is interesting — but it is not yet evidence that geometry is special.

## The control that matters

`householder2` applies two **dense** token-selective Householder reflections. This is here specifically because Householder-product transitions are established prior art in modern state-tracking LRNNs (e.g. DeltaProduct), and because the negative-eigenvalue/state-tracking literature already shows why richer transition algebra matters.

In the first `perm3` gate, `householder2` solved the task and extrapolated perfectly to 4x/16x training length in the tested seed, with even smaller state than the local geometric model. So the current evidence says:

> KYY has rediscovered that reflection products are excellent state trackers. It has **not** yet shown that local geometry beats generic Householder structure.

That is exactly the distinction the next experiments must test.

## Baselines

- `diag_signed` — token-selective signed diagonal recurrence.
- `complex_diag` — token-selective independent 2D rotary/complex blocks.
- `householder2` — product of two dense Householder reflections; strong algebraic control.
- `gru` — dense nonlinear recurrent reference.
- `geom_wave` — sparse graph-Laplacian second-order wave recurrence.
- `geom_scatter` — sparse product of local reciprocal 2-port scatterers.

Every run reports state size, trainable parameter count, accuracy at multiple sequence lengths, wall time, and an operator/eigenspectrum summary where available.

## Tasks

The first gate uses exact synthetic state-tracking tasks:

- running parity;
- running count modulo 3;
- set/reset/toggle flip-flop;
- composition of generators of `S3` (non-commutative finite-state tracking).

Train at one length, then evaluate at longer lengths without retraining.

## Run

```bash
pip install -r requirements.txt
python benchmark.py --quick
```

A fuller sweep:

```bash
python benchmark.py \
  --models diag_signed complex_diag householder2 geom_wave geom_scatter gru \
  --tasks parity mod3 flipflop perm3 \
  --train-length 32 --test-lengths 32 64 128 256 \
  --steps 1500 --seeds 0 1 2
```

Topology controls for the geometric models:

```bash
python benchmark.py --models geom_scatter --tasks perm3 --topology ring
python benchmark.py --models geom_scatter --tasks perm3 --topology path
python benchmark.py --models geom_scatter --tasks perm3 --topology matching
python benchmark.py --models geom_scatter --tasks perm3 --topology disconnected
```

`matching` is particularly useful: it leaves only independent local pairs, removing the overlapping path by which local operations become global/non-commutative.

## What would now count as a geometric win?

Not “it can solve parity.” Generic reflection products already can.

A useful result would be one of:

1. a connected local geometry reaches a task/length/accuracy point at lower measured compute or hardware cost than a generic reflector baseline;
2. ring/path topology succeeds where a parameter-matched non-overlapping `matching` control fails;
3. a geometry has better robustness to quantization/noise/local parameter perturbation;
4. the same learned local operator maps naturally onto the TWC/TW-1A fabric without a dense routing penalty;
5. geometry produces useful modal structure on tasks where the input itself has spatial/relational locality.

A null result is valuable. If generic Householder/PD-style sparse transitions dominate, the stronger Geometric-Neuron architectural claim is not earned by these benchmarks.

## Prior-art checkpoint

Before the first code pass, KYY checked the obvious neighbouring lines:

- Mamba-3 and complex/MIMO SSM updates;
- negative-eigenvalue and non-triangular state-tracking results;
- DeltaProduct / products of Householder transformations;
- PD-SSM / Flash PD-SSM structured sparse state transitions;
- graph SSMs and message-passing SSMs;
- block-diagonal/higher-order LRNNs;
- unitary/orthogonal RNNs and Givens/Householder parameterizations.

So KYY is **not** claiming “structured recurrence,” “complex state,” “graph SSM,” or “Householder state tracking” as new. The unearned-but-testable remainder is the Geometric Neuron commitment:

> **Does constraining state mixing to an actual local geometry buy anything once the algebraic baselines are strong?**

The project rule remains:

> **Do not hype, do not lie, just show.**
